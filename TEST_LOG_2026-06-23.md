## Current Validation Flow

Use the ESP on `COM8`; the PSoC PC UART on `COM6` is not expected to work in
the current programming/debug mode.

1. Open the ESP serial monitor on `COM8`.
2. Send `adc` to get a direct ADC snapshot for every HAMMER calibration stage.
3. Send `cal` to run automatic calibration.
4. Wait for:

   ```text
   CAL_DONE,ok=1
   CFG_ACK,sub=0xB5,val=1,expected=1,ok=1
   ```

5. Send `adc` again. For the current HAMMER setup, both stages should report
   near `target_mV=1024` and remain inside the `6000` count tolerance.
